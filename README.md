# Overcook demo clone

A standalone, dependency-free interface recreation of the public Overcook demo.

## Run locally

Open `index.html` in a modern browser. No build step or hosting is required.

## Included

- Desktop and mobile experience selector
- Desktop channel grid, search, filters, and stream detail layout
- Local demo chat and prediction-market interactions
- Mobile-style vertical feed with swipe and keyboard navigation

The stream panels use locally generated mock visuals. The original demo's playable clips are not bundled; add video files separately if you have them and want local playback.
